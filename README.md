# E5 DSIA 5102A - Application Fullstack data

_________________

## Critères d'évaluation du projet
### Développement d'une application WEB
---------------------------------------
 
Sujet libre (Gestion d'un blog, création d'un catalogue de produits...)
 
---------------------------------------
Rendu:
- Lien vers un Repo GitHub (à référencer dans ce fichier)
- Le projet devra contenir au minimum:
- Un README expliquant le choix du sujets, son implémentation, les difficultés rencontrées, les pistes d'améliorations possibles etc.
- Un Dockerfile permettant de construire l'image de l'application
- Un docker compose comportant au moins deux services (API + BDD)
- Une gestion d'utilisateurs
- Un système d'authentification pour des routes d'API sécurisées
- Gestion des erreurs HTTP
- Une suite de tests automatisés
- Un script permettant de remplir la base de données au lancement du projet pourra accompagner le rendu  
- Soyez créatifs, que ce soit sur le choix du sujet ou dans les fonctionnalités de l'application
